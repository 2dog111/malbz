## Остаточные ограничения

- Для GPT-5.6 не подтверждены итоговый рублёвый тариф, НДС, сервисная наценка, минимальный платёж, SLA и обработка логов. До подтверждения CTA только запрашивает расчёт.
- Для оффера Яндекс Директ 45 000 ₽ / 35 000 ₽ нет данных, которые доказывают механику сделки. Оффер скрыт.
- Для Lusiesta Studio и Telegram Target Parser не заполнены владелец лицензии, владелец поддержки и условия возврата.
- Контакты и точный текст информации о продавце/операторе не предоставлены; самостоятельно они не добавлялись.
- `dataLayer` фиксирует события локально, но без подключённого счётчика они не отправляются во внешнюю аналитику.
